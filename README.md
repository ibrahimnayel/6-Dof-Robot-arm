# 6-Dof-Robot-arm
A fully simulated 6DOF robotic arm designed in SolidWorks, integrated into MATLAB Simscape, and controlled via a custom-built GUI with real-time joint angle manipulation and automated torque calculation.

## Features

- ✅ **3D CAD Model**: Modeled using SolidWorks.
- ✅ **Simscape Integration**: Exported to MATLAB Simscape for dynamic simulation.
- ✅ **GUI Controller**: Developed in MATLAB App Designer with 6 sliders to control each joint.
- ✅ **Real-Time Joint Control**: Users can manipulate each joint angle through the GUI.
- ✅ **Automated Torque Calculation**: The  GUI computes and displays the required torque for each joint.

## Project Components

- `SolidWorks_Model/`: Contains the original 3D model files.
- `Simscape_Model/`: Includes the Simscape files for simulation.
- `GUI_Controller/`: MATLAB files for the graphical user interface.
- `README.md`: This documentation file.
